# Caesar Cipher

A Python implementation of the classic Caesar Cipher, created as part of the freeCodeCamp Python certification curriculum.

## How It Works
The Caesar Cipher is a simple substitution cipher where each letter in the plaintext is shifted by a fixed number of positions down the alphabet. 

## Features
- Encrypts and decrypts text messages using a specified shift key.
- Preserves spaces and special characters.

## How to Run
Run the script using Python 3:
```bash
python caesar_cipher.py
